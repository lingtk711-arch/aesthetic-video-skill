# 21条参考素材：风格档案 v0.3

承接v0.2。21条总时长64分31.3秒；V17–V21为本次新增。编号按用户上传顺序，不代表发布时间或表现排序。
本轮5条：60张均匀抽样帧、15张开头帧、48张0.5秒效果窗口、543个每2秒OCR采样、本地base模型语音初稿、全时长视觉变化候选及整条混音响度测量。不是完整人工逐帧逐句视听校对。累计OCR抽样1935个。

## 本轮增加的可迁移机制
- V17：前作卡片+历史/文化材料+真人立场，可以组织“问题来源→背景→传播→边界”的论述。统计、年代、引语需另核验，不照抄原片事实主张。
- V18：人物案例与类似大衣对照之后转入面料、版型、色系和配饰，适合抽象感觉→可见机制→行动。开头审美推断道德的主张不作为野桃识人规则。
- V19：街景、穿搭、真人和章节卡交替，能容纳两条城市路径；不把地名当装饰，也不把文化因果当已验证事实。
- V20：全身、颈部细节和并排对照反复围绕衣物接口，给画面一个明确观察任务。
- V21：概念标签紧贴不同例图，随后返回真人解释；标签可能提供分类，也可能造成过载，不能自动说越多越留人。

## 可具体定位的视觉形式
V17 16.5–17秒帖子卡从小到大，18秒附近见纵向模糊状态；精确动画时长和算法未知。
V20 16–23.5秒，单人→双人→暗场视频→并排秀场图；抽样不足以确认每处转场类型。
V21 20.5–23秒，概念标签配例图；17–18.5秒可见边框式包装。
这些形式的制作建议在editing-recipes.md，OBSERVED与PROPOSED分开。不要把建议参数说成原作者参数。

## 音频
音轨有语音，机器稿已建；歌词、专名与句子仍有误字。未可靠听辨曲目、段数、音效和拍点。
混合音轨测量见audio-playbook.md，不能用它证明BGM被压低或抬高；也不把原片高响度当推荐目标。

## 生成时优先遵循
完整口播→段落功能→逐句素材需求→镜头表→有理由的效果→声音占位/实测表→发布实验。只有一个选题也要完成初稿；参数与来源未定的部分明确标状态，不能用“待补”替代整份制作包。
不固定生僻词密度、金句频率、每句切图或统一调色。借鉴功能结构，保留野桃自己的判断与素材。
